# Bug audit remediation

The audit started at `bbb79192f4daf245e6a892ef04d90c6052f6ddb6` and covers
the Rust product, shell adapters, update handling, and the excluded prototype
driver and build tooling. The initial 25 confirmed findings are tracked in 24 new
issues (#152 through #175) and the reopened #66. Preparing release 0.1.2 added
the version-bumper test finding #177. This is a bounded source
review and regression test pass, not a claim that the repository has no other
bugs. The version bump to 0.1.2 is separate from the original audit.

## Validation boundaries

Tests use temporary files and mocked installer/update operations. The audit
does not modify the user's live adapters, profiles, package installation, or
scheduled tasks. Automated source fixtures do not establish native UI rendering
or real Store deployment behavior.

The five ignored Windows tests require a real foreground browser or Search
window, a low-integrity UI harness, native Task Scheduler registration, or a
release timing run. Their runtime behavior has not been established by the
passing automated suite.

The prototype driver is excluded from normal packages. It was compiled, never
loaded on the host. Keep #170 open until the checkpointed VM routing controls
in `docs/driver-lab.md` pass. The separate rename/hard-link investigation
[#49](https://github.com/faratech/fwdslash/issues/49) also remains open.
