- Everything about updating Forward Slash Windows is now in one place, on the About page.
- The app no longer offers to install an update that is already installing.
- When the Microsoft Store cannot be reached, the app says so instead of telling you that you are up to date.
- The app no longer offers you a version you already have.
- An update now tries every way it can to install itself, instead of giving up after the first one fails.
- Command Prompt no longer leaves a temporary file behind each time you change folder with a Linux path.
