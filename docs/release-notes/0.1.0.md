# Forward Slash Windows 0.1.0

## Major fixes

- **Self-update no longer hangs the settings window.** Route 1a now watches queued Store items for a bounded 3-minute admission window instead of 45 minutes in-process, leaving the window free to close or the broker to serve input. The Store's own install queue is reconciled before queueing, so leftover items cannot shadow new requests. The watchdog now relaunches the broker if an install times out, so `/` paths keep working. The settings window bounds the update verbs, kills children past their ceiling, and captions the progress ring.
- **Cleaned up leftover update tasks.** A garbage-collection sweep on every packaged `check`/`status` removes tasks, sidecars and lock tokens older than 70 minutes, so attempts killed mid-flight no longer fail the next install for an hour.
- **The Store's scan cooldown is now respected.** The install service answers re-checks inside its ~30-minute scan cooldown from cache with 0 applicable updates; `install` now trusts a cached newer offer and `check` keeps it standing inside the cooldown window.
