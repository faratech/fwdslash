- Updating from inside the app no longer gets stuck saying "Installing" forever. The Microsoft Store takes the install over, and the app tells you it is running in the background.
- Forward Slash Windows comes back on its own when an update does not finish, instead of staying closed until you sign in again.
- An update the app has already found no longer disappears before you get a chance to install it.
- An update that was interrupted no longer stops you from trying again for an hour.
- Files and scheduled tasks left behind by earlier update attempts are cleaned up on their own.
