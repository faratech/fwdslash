- Updating from inside the app no longer gets stuck saying "Installing" forever. The Microsoft Store takes the install over and the app tells you it is running in the background.
- Forward Slash Windows now comes back by itself when an update does not finish, instead of staying closed until you sign in again.
- An update attempt that was interrupted no longer blocks the next one for an hour.
- An update that was just found is no longer forgotten by the check that follows it.
- Leftover files and scheduled tasks from earlier update attempts are cleaned up on their own.
